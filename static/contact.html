Frequently Asked Questions

Quick answers about courses, prerequisites, and learning paths.

Are all the courses really 100% free?
Yes, absolutely! Every video course, complete source code repository, Helm chart, and Terraform template is free and open source. No subscription or paywall required.
What prerequisites are needed before starting?
Our "Zero to Hero" series starts with absolute fundamentals like Linux terminal navigation, Git, and networking basics. No prior cloud experience is required.
How do I get help if my deployment or build breaks?
Join our exclusive Slack community through the link above, or submit an issue in our GitHub repository. We also host live stream debugging sessions to walk through issues together.
Can I contribute to these educational projects?
We enthusiastically welcome pull requests, documentation improvements, translation fixes, and sample manifests. Feel free to open a PR on our GitHub repos!
